# predictive-analytics-historical-data
An interactive Streamlit dashboard for predictive analytics using historical data. Upload CSV datasets, clean and preprocess data, analyze trends, train a Linear Regression model, evaluate performance, visualize actual vs predicted values, and forecast future trends with downloadable predictions.
